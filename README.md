# Глянец: Стражницы

Офлайн-прототип (PWA) для iPhone: tower defense на сетке 3×5 со слиянием стражниц.

## Как открыть

Нужен любой статический хостинг (или локальный сервер). Сайту нужен HTTP/HTTPS — просто открыть `index.html` файлом в Safari можно, но офлайн-установка PWA так не заработает.

На компьютере:

```
cd glyanets
python3 -m http.server 8080
```

Затем откройте в браузере `http://127.0.0.1:8080/` или с телефона в той же Wi‑Fi сети — `http://IP-компьютера:8080/`.

На iPhone в Safari: «Поделиться» → «На экран „Домой“», чтобы запустить как приложение.

Прогресс хранится в localStorage этого браузера. Покупок за деньги нет.
